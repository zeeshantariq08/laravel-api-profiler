# Contributing

Thank you for considering contributing to Laravel API Profiler!

## How to Contribute

### Reporting Bugs

If you find a bug, please open an issue on GitHub with:

- Clear description of the bug
- Steps to reproduce
- Expected vs actual behavior
- Laravel and PHP versions
- Any relevant error messages

### Suggesting Features

Feature suggestions are welcome! Please open an issue with:

- Clear description of the feature
- Use case/benefit
- Possible implementation approach (optional)

### Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Add tests if applicable
5. Ensure code follows Laravel conventions
6. Update documentation if needed
7. Commit your changes (`git commit -m 'Add amazing feature'`)
8. Push to the branch (`git push origin feature/amazing-feature`)
9. Open a Pull Request

### Code Style

- Follow PSR-12 coding standards
- Use Laravel's coding conventions
- Add comments for complex logic
- Keep functions focused and small

### Testing

- Test your changes thoroughly
- Ensure existing functionality still works
- Add tests for new features (when test suite is available)

## Development Setup

```bash
# Clone the repository
git clone https://github.com/zeeshantariq08/laravel-api-profiler.git

# Install dependencies
composer install

# Link to a Laravel project for testing
# In your Laravel project's composer.json:
{
    "repositories": [
        {
            "type": "path",
            "url": "../laravel-api-profiler"
        }
    ]
}
```

## Questions?

Feel free to open an issue for any questions or discussions.

Thank you for contributing! 🎉
